# Protein Language Models for Orthologous Group Classification

## Overview
Master 2 Bioinformatics internship project (CRBS / ICube, Université de Strasbourg). The objective is to evaluate Protein Language Model (PLM) embeddings for the classification of protein sequences into  Orthologous Groups.
